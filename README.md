# Rock-Paper-Scissors

A simple interactive Rock Paper Scissors game built using HTML, CSS, and JavaScript.

## Features

* Choose between Rock, Paper, and Scissors
* Previous/Next buttons for selection
* Random computer choice
* Play multiple rounds
* Automatic score tracking
* Round-by-round results
* Displays the computer's choice
* Displays the final winner
* Rock, Paper, and Scissors images

## Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* Event Listeners

## How It Works

1. The player chooses the number of rounds.
2. Rock, Paper, or Scissors is selected using the navigation buttons.
3. The player clicks **Done** to play the round.
4. The computer generates a random choice.
5. The choices are compared to determine the winner.
6. The score is updated.
7. After all rounds, the final winner is displayed.
